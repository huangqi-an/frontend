# 动态表单引擎：从状态模型到可运行实现

动态表单的难点不是“根据 JSON 渲染几个输入框”，而是当字段之间存在联动、副作用、数组增删和局部重算时，仍然能够回答三个问题：

1. 哪份数据是业务事实？
2. 哪份数据只是视图计算结果？
3. 一次修改应该触发哪些逻辑，什么时候停止？

如果这三个问题没有定义清楚，代码通常会退化成“表达式直接改 schema、数组项靠 index 复用、所有联动全量重跑、组件里到处写 if/else”。本篇不再按功能堆积代码，而是先定义状态边界和调度规则，再给出一个可以复制到独立 Vue 3 项目中运行的完整实现。

> 文中的“完整可运行”指：复制 `form-engine/` 目录结构后，安装依赖即可启动 demo、运行 Vitest 和 `vue-tsc`。它不是当前仓库现有 package 的发布代码，也不会写入 `labs/`。

## 一、设计目标与非目标

### 1.1 目标

- 用 Vue 3 Composition API 构建一套可独立运行的表单引擎。
- 支持普通字段、对象嵌套字段和单层 repeatable 数组字段。
- 支持字段级表达式，例如控制 `visible`、`props.disabled`、`rules[0].required`。
- 支持声明式副作用，v1 实现 `clear`。
- 支持表达式依赖收集、增量触发、副作用级联和循环保护。
- 支持组件注册表，渲染层不绑定 Element Plus 或其他 UI 库。
- 支持独立 identity map，数组增删时不向业务 model 写入 `_id`。
- 所有路径使用统一语法：`a.b[0].c`。

### 1.2 非目标

- 不实现嵌套 repeatable。v1 在 schema 编译阶段明确报错，而不是产生难以排查的隐式行为。
- 不实现异步表达式、远程 options、异步校验。它们应该通过明确的 async 状态接口扩展，而不是让表达式求值变成 Promise。
- 不实现完整表单校验器。`rules` 只作为运行时状态被表达式修改，实际校验交给后续集成层。
- 不追求“表达式可以引用另一个表达式的结果”。v1 的依赖只来自 model 路径，避免在没有拓扑排序和环检测的情况下制造隐式链路。
- 不发布 npm 包，不处理 SSR 和跨标签页同步。

### 1.3 核心判断

原方案最需要修正的不是目录命名，而是状态归属：

```text
schema       业务字段的结构定义，只读
model        真正要提交、要持久化的业务数据
runtimeState 表达式计算出的 UI 状态，例如 visible、disabled、options
```

三层分开之后，渲染层只读 schema 和 runtimeState，表单值只读写 model。这样既能保证响应式更新，也不会让表达式结果污染字段定义。

## 二、三层状态模型

### 2.1 schema：描述“有什么”

`schema` 只回答：

- 字段叫什么，路径是什么。
- 使用哪个控件。
- 初始 props、custom、rules 是什么。
- 是否存在 children 或 itemSchema。
- 有哪些表达式和副作用声明。

编译后的 schema 会被冻结。运行时不能直接修改 `field.props.disabled`，因为那会让“字段定义”和“字段状态”混在一起。

### 2.2 model：描述“业务值是什么”

`model` 是唯一应该被提交的数据源：

```text
{
  name: "Ada",
  userType: "admin",
  dept: "tech",
  emergencyContacts: [
    { name: "Tom", phone: "13800000000", email: "tom@example.com" }
  ]
}
```

业务代码统一调用 `engine.setValue(path, value)`。直接写 `model.xxx` 不会进入调度器，表达式和副作用不会触发。

### 2.3 runtimeState：描述“现在怎么显示”

表达式结果放在独立的响应式 state 中：

```text
{
  "dept": {
    path: "dept",
    props: { disabled: true },
    custom: { options: [] },
    rules: [{ required: false }],
    visible: true
  }
}
```

渲染组件读取 `getFieldState(path)`，而不是读取并修改 `CompiledField`。表达式目标使用字段相对路径：

```text
expressions: {
  "visible": '$model.userType === "admin"',
  "props.disabled": "!$model.name",
  "rules[0].required": '$model.userType === "admin"',
  "custom.options": "$functions.getDeptOptions($model.userType)"
}
```

### 2.4 为什么不用 JSON 深拷贝 schema

`JSON.parse(JSON.stringify(schema))` 会丢失 `undefined`、`Date`、函数和部分特殊对象；它也只能解决初始化复制，不能解决后续响应式追踪。本项目用 `structuredClone` 处理初始数据，并让 runtimeState 承担所有动态结果。

## 三、运行流程

### 3.1 初始化

```text
原始 schema
  -> compileSchema：校验并补齐 path
  -> 建立静态 fieldMap
  -> 根据 model 中已有数组建立 repeatable 运行时字段
  -> 为静态字段和数组项字段建立 runtimeState
  -> 编译表达式与副作用规则
  -> 构建依赖索引和副作用索引
  -> 执行一次全部表达式
  -> 交给渲染层
```

初始化只执行表达式，不执行副作用。副作用代表“值变化后的清理行为”，不应在表单第一次建立时清空用户传入的初始 model。

### 3.2 一次字段修改

```text
用户输入
  -> engine.setValue(path, value)
  -> 写入 model
  -> 将 path 放入调度队列
  -> 找到依赖该 path 的表达式并执行
  -> 把结果写入 runtimeState
  -> 找到 sourcePath 匹配的副作用
  -> 执行 clear，写入新的 model path
  -> 新 path 再次进入队列
  -> 达到稳定状态或超过 maxSteps
```

调度器采用有限步 BFS，而不是递归执行。这样副作用级联和循环保护都集中在一个地方。

### 3.3 数组增删

```text
append/remove
  -> 修改 model 中的数组
  -> 同步 identityMap
  -> 删除旧的运行时 field/state/rule
  -> 按最新 index 重建
  -> 重建依赖索引
  -> 触发数组路径下方的全部表达式
```

删除中间项时，原 index 2 会变成 index 1。数组项字段配置和表达式规则必须随之重建，不能继续复用旧的 `contacts[2].phone`。

### 5.3 `src/form-engine/path.ts`

路径系统是引擎的第一层基础设施。所有路径都必须是规范形式；不规范的输入直接报错，而不是猜测用户意图。

```ts
import { FormEngineError } from "./errors";
import type { Path, PathSegment } from "./types";

const KEY_PATTERN = /^[A-Za-z_$][\w$]*/;

export function parsePath(path: Path): readonly PathSegment[] {
  if (!path) {
    throw new FormEngineError("PATH_INVALID", "Path cannot be empty.");
  }

  const segments: PathSegment[] = [];
  let cursor = 0;
  let expectKey = true;

  while (cursor < path.length) {
    const char = path[cursor];

    if (expectKey) {
      const rest = path.slice(cursor);
      const match = KEY_PATTERN.exec(rest);

      if (!match?.[0]) {
        throw new FormEngineError("PATH_INVALID", `Invalid path key at "${path}".`);
      }

      segments.push({ kind: "key", key: match[0] });
      cursor += match[0].length;
      expectKey = false;
      continue;
    }

    if (char === ".") {
      cursor += 1;
      expectKey = true;
      continue;
    }

    if (char === "[") {
      const end = path.indexOf("]", cursor);

      if (end < 0) {
        throw new FormEngineError("PATH_INVALID", `Missing "]" in path "${path}".`);
      }

      const token = path.slice(cursor + 1, end);

      if (!/^\d+$/.test(token)) {
        throw new FormEngineError("PATH_INVALID", `Array index must be numeric in "${path}".`);
      }

      segments.push({ kind: "index", index: Number(token) });
      cursor = end + 1;
      continue;
    }

    throw new FormEngineError(
      "PATH_INVALID",
      `Expected "." or "[" at position ${cursor} in path "${path}".`,
    );
  }

  if (expectKey) {
    throw new FormEngineError("PATH_INVALID", `Path cannot end with ".": "${path}".`);
  }

  return segments;
}

export function serializePath(segments: readonly PathSegment[]): Path {
  return segments
    .map((segment) => (segment.kind === "key" ? segment.key : `[${segment.index}]`))
    .join(".")
    .replaceAll(".[", "[");
}

export function normalizePath(path: Path): Path {
  return serializePath(parsePath(path));
}

export function isRecord(value: unknown): value is Record<string, unknown> {
  return value !== null && typeof value === "object" && !Array.isArray(value);
}

export function getByPath(source: unknown, path: Path): unknown {
  let current = source;

  for (const segment of parsePath(path)) {
    if (segment.kind === "key") {
      if (!isRecord(current)) return undefined;
      current = current[segment.key];
      continue;
    }

    if (!Array.isArray(current)) return undefined;
    current = current[segment.index];
  }

  return current;
}

export function setByPath(target: Record<string, unknown>, path: Path, value: unknown): void {
  const segments = parsePath(path);
  let current: Record<string, unknown> | unknown[] = target;

  for (let index = 0; index < segments.length - 1; index += 1) {
    const segment = segments[index];
    const nextSegment = segments[index + 1];

    if (!segment || !nextSegment) {
      throw new FormEngineError("PATH_INVALID", `Cannot set path "${path}".`);
    }

    const key = segment.kind === "key" ? segment.key : segment.index;
    const currentValue = Array.isArray(current) ? current[Number(key)] : current[String(key)];
    const needsArray = nextSegment.kind === "index";
    const compatible =
      (needsArray && Array.isArray(currentValue)) || (!needsArray && isRecord(currentValue));

    if (!compatible) {
      const nextContainer: Record<string, unknown> | unknown[] = needsArray ? [] : {};

      if (Array.isArray(current)) {
        current[Number(key)] = nextContainer;
      } else {
        current[String(key)] = nextContainer;
      }

      current = nextContainer;
      continue;
    }

    current = currentValue as Record<string, unknown> | unknown[];
  }

  const last = segments.at(-1);

  if (!last) {
    throw new FormEngineError("PATH_INVALID", `Cannot set path "${path}".`);
  }

  if (last.kind === "key") {
    if (Array.isArray(current)) {
      throw new FormEngineError("PATH_INVALID", `Key "${last.key}" cannot be used on an array.`);
    }
    current[last.key] = value;
    return;
  }

  if (!Array.isArray(current)) {
    throw new FormEngineError("PATH_INVALID", `Index "${last.index}" cannot be used on an object.`);
  }

  current[last.index] = value;
}

export function deleteByPath(target: Record<string, unknown>, path: Path): boolean {
  const segments = parsePath(path);
  const last = segments.at(-1);

  if (!last) return false;

  const parentPath = serializePath(segments.slice(0, -1));
  const parent = parentPath ? getByPath(target, parentPath) : target;

  if (!parent) return false;

  if (last.kind === "key" && isRecord(parent)) {
    return delete parent[last.key];
  }

  if (last.kind === "index" && Array.isArray(parent)) {
    parent.splice(last.index, 1);
    return true;
  }

  return false;
}

export function isPathAncestor(ancestor: Path, descendant: Path): boolean {
  return (
    ancestor === descendant ||
    descendant.startsWith(`${ancestor}.`) ||
    descendant.startsWith(`${ancestor}[`)
  );
}

export function pathsIntersect(left: Path, right: Path): boolean {
  return isPathAncestor(left, right) || isPathAncestor(right, left);
}

export function joinPath(parent: Path, child: Path): Path {
  if (!parent) return normalizePath(child);
  if (!child) return normalizePath(parent);
  return normalizePath(`${parent}.${child}`);
}

export function isPlainEmptyValue(value: unknown): boolean {
  return (
    value === undefined ||
    (Array.isArray(value) && value.length === 0) ||
    (isRecord(value) && Object.keys(value).length === 0)
  );
}
```

## 六、表达式子系统

### 6.1 表达式应该解决什么

表达式只负责把 model 和当前字段上下文映射成一个运行时值：

```text
布尔值  -> visible / props.disabled / rules[0].required
数组    -> custom.options / props.columns
对象    -> custom.meta
标量    -> props.placeholder
```

表达式不应该：

- 写 model。
- 发请求。
- 返回 Promise。
- 依赖执行顺序。
- 通过 `this` 或全局变量隐藏依赖。

这些限制不是保守，而是为了让“改一个字段后会发生什么”可以被静态分析出来。

### 6.2 依赖收集

`collectDependencies` 只识别两类根变量：

- `$model.xxx`：依赖业务 model 的绝对路径。
- `$item.xxx`：依赖当前 repeatable 项内的相对路径。

它不是完整 JavaScript 解析器，因此不承诺识别 `$model[key]`、解构、函数内部引用或动态拼接路径。完整 AST 分析也做不到所有情况。这个边界必须在 schema 编写规范中说清楚，而不是让运行时猜。

### 6.3 求值器适配器

默认求值器使用受信 schema 加 `Function`：

- 优点：无额外依赖，表达力接近 JavaScript。
- 缺点：不能隔离全局对象，不能用于用户上传或在数据库中保存的 schema。
- 约束：页面必须允许 `unsafe-eval` CSP；生产系统若接收不可信 schema，应替换为 AST 白名单求值器。

### 6.4 `src/form-engine/expression.ts`

```ts
import { FormEngineError } from "./errors";
import type { CompiledExpression, ExpressionEvaluator, ParsedDependency } from "./types";

const DEPENDENCY_PATTERN = /\$(model|item)((?:\??\.[A-Za-z_$][\w$]*|\[\d+])*)/g;

export function collectDependencies(expression: string): readonly ParsedDependency[] {
  const dependencies = new Map<string, ParsedDependency>();

  for (const match of expression.matchAll(DEPENDENCY_PATTERN)) {
    const scope = match[1];
    const rawPath = match[2] ?? "";
    const path = rawPath.replace(/\?\./g, ".").replace(/^\./, "");

    if (!scope || !path) continue;

    const type = scope === "model" ? "model" : "item";
    const key = `${type}:${path}`;

    if (!dependencies.has(key)) {
      dependencies.set(key, { type, path });
    }
  }

  return [...dependencies.values()];
}

export function createFunctionExpressionEvaluator(): ExpressionEvaluator {
  const cache = new Map<string, CompiledExpression>();

  return {
    compile(expression: string): CompiledExpression {
      const cached = cache.get(expression);
      if (cached) return cached;

      let runner: (...args: unknown[]) => unknown;

      try {
        runner = new Function(
          "$model",
          "$item",
          "$index",
          "$self",
          "$functions",
          `"use strict"; return (${expression});`,
        ) as (...args: unknown[]) => unknown;
      } catch (cause) {
        throw new FormEngineError(
          "EXPRESSION_COMPILE",
          `Cannot compile expression: ${expression}`,
          { expression, cause },
        );
      }

      const compiled: CompiledExpression = (context) =>
        runner(context.$model, context.$item, context.$index, context.$self, context.$functions);

      cache.set(expression, compiled);
      return compiled;
    },
  };
}
```

### 6.5 表达式规则如何生成

静态字段的表达式目标相对当前字段：

```text
ownerPath: dept
targetPath: props.disabled
最终状态位置: runtimeState["dept"].props.disabled
```

数组项字段在运行时实例化后，ownerPath 已经包含 index：

```text
ownerPath: emergencyContacts[0].phone
targetPath: props.disabled
依赖: $item.name -> emergencyContacts[0].name
```

因此表达式规则不需要在运行时重新推导相对路径。数组重建时，规则整体重建即可。

## 七、schema 编译

### 7.1 编译阶段做哪些事

`compileSchema` 只做一次，负责：

- 为静态字段和 children 生成规范 path。
- 校验同层级字段名唯一。
- 校验 repeatable 必须有非空 itemSchema。
- 拒绝嵌套 repeatable。
- 拒绝 component、children、repeatable 之间的歧义组合。
- 建立静态 fieldMap 和 repeatable 列表。
- 冻结编译结果，防止运行时误改。

编译阶段不应该：

- 读取表单值。
- 执行表达式。
- 创建数组项运行时字段。
- 触发副作用。

### 7.2 `src/form-engine/schema.ts`

```ts
import { FormEngineError } from "./errors";
import { joinPath } from "./path";
import type { CompiledField, FormField, FormRule } from "./types";

export interface CompiledSchema {
  readonly fields: readonly CompiledField[];
  readonly fieldMap: Readonly<Record<string, CompiledField>>;
  readonly repeatables: readonly CompiledField[];
}

function cloneRule(rule: FormRule): FormRule {
  return { ...rule };
}

function deepFreeze<T>(value: T): T {
  if (value && typeof value === "object" && !Object.isFrozen(value)) {
    Object.freeze(value);

    for (const child of Object.values(value)) {
      deepFreeze(child);
    }
  }

  return value;
}

function validateFieldShape(raw: FormField, inRepeatable: boolean): void {
  const hasChildren = Boolean(raw.children?.length);
  const hasComponent = Boolean(raw.component);
  const isRepeatable = raw.repeatable === true;

  if (!raw.field && !hasChildren) {
    throw new FormEngineError("SCHEMA_INVALID", "Every field must define field or children.");
  }

  if (isRepeatable && !raw.field) {
    throw new FormEngineError("REPEATABLE_INVALID", "A repeatable field must define field.");
  }

  if (isRepeatable && inRepeatable) {
    throw new FormEngineError(
      "REPEATABLE_INVALID",
      `Nested repeatable is not supported: ${raw.field ?? "(anonymous)"}.`,
    );
  }

  if (isRepeatable && !raw.itemSchema?.length) {
    throw new FormEngineError(
      "REPEATABLE_INVALID",
      `Repeatable field "${raw.field}" needs a non-empty itemSchema.`,
    );
  }

  if (isRepeatable && hasChildren) {
    throw new FormEngineError(
      "REPEATABLE_INVALID",
      `Repeatable field "${raw.field}" cannot also define children.`,
    );
  }

  if (hasComponent && hasChildren) {
    throw new FormEngineError(
      "SCHEMA_INVALID",
      `Field "${raw.field ?? "(anonymous)"}" cannot define both component and children.`,
    );
  }

  if (!isRepeatable && !hasComponent && !hasChildren) {
    throw new FormEngineError(
      "SCHEMA_INVALID",
      `Leaf field "${raw.field ?? "(anonymous)"}" needs a component.`,
    );
  }

  if (inRepeatable && !raw.field) {
    throw new FormEngineError("REPEATABLE_INVALID", "Every field in itemSchema must define field.");
  }
}

function compileFields(
  rawFields: readonly FormField[],
  parentPath: string,
  inRepeatable: boolean,
): CompiledField[] {
  const siblingNames = new Set<string>();

  return rawFields.map((raw, index) => {
    validateFieldShape(raw, inRepeatable);

    const field = raw.field?.trim() || null;

    if (field && siblingNames.has(field)) {
      throw new FormEngineError(
        "SCHEMA_INVALID",
        `Duplicate field "${field}" under "${parentPath || "<root>"}".`,
      );
    }

    if (field) siblingNames.add(field);

    const path = field ? joinPath(parentPath, field) : parentPath;
    const hasChildren = Boolean(raw.children?.length);
    const repeatable = raw.repeatable === true;

    const children = hasChildren ? compileFields(raw.children ?? [], path, inRepeatable) : [];

    const itemSchema = repeatable ? compileFields(raw.itemSchema ?? [], "", true) : [];

    return {
      key: path || `group-${index}`,
      field,
      path,
      parentPath: parentPath || null,
      component: raw.component ?? null,
      props: { ...(raw.props ?? {}) },
      custom: { ...(raw.custom ?? {}) },
      rules: (raw.rules ?? []).map(cloneRule),
      expressions: { ...(raw.expressions ?? {}) },
      effects: (raw.effects ?? []).map((effect) => ({
        ...effect,
        targets: [...effect.targets],
      })),
      ui: { ...(raw.ui ?? {}) },
      children,
      repeatable,
      itemSchema,
      itemRoot: null,
      itemIndex: null,
    };
  });
}

function collectStaticFieldMap(
  fields: readonly CompiledField[],
  fieldMap: Record<string, CompiledField>,
): void {
  for (const field of fields) {
    if (field.path && !fieldMap[field.path]) {
      fieldMap[field.path] = field;
    }

    collectStaticFieldMap(field.children, fieldMap);
  }
}

function collectRepeatables(fields: readonly CompiledField[], repeatables: CompiledField[]): void {
  for (const field of fields) {
    if (field.repeatable) repeatables.push(field);
    collectRepeatables(field.children, repeatables);
  }
}

export function compileSchema(rawSchema: readonly FormField[]): CompiledSchema {
  if (!rawSchema.length) {
    throw new FormEngineError("SCHEMA_INVALID", "Schema cannot be empty.");
  }

  const fields = compileFields(rawSchema, "", false);
  const fieldMap: Record<string, CompiledField> = {};
  const repeatables: CompiledField[] = [];

  collectStaticFieldMap(fields, fieldMap);
  collectRepeatables(fields, repeatables);

  return deepFreeze({
    fields,
    fieldMap,
    repeatables,
  });
}
```

### 7.3 为什么要冻结编译结果

冻结能阻止两种经常出现的隐性 bug：

1. 表达式执行时直接写 `field.props`，导致同一个 schema 被不同表单实例共享后互相污染。
2. 数组项重建时误改父级 schema，导致下一次 append 使用了上一种 index 的配置。

如果确实需要更新字段结构，正确做法是重建 schema 和引擎，而不是在运行中修改 `CompiledField`。

## 八、引擎与调度器

### 8.1 引擎职责

引擎是唯一知道“修改后应该做什么”的模块。它同时管理四组内部状态：

```text
runtimeFieldMap  path -> CompiledField
runtimeStates    path -> RuntimeFieldState
identityMap      arrayPath -> itemId[]
repeatableMap    arrayPath -> 当前数组项规则和字段
```

外部只通过 `FormEngine` 接口访问，不直接接触内部 Map。

### 8.2 为什么需要 identity map

数组项的展示 key 不能直接用 index。删除第 0 项之后，原来的第 1 项会被 Vue 复用为新的第 0 项，如果它内部有未受控状态，就会出现“输入框内容看起来跳项”的问题。

identity map 的做法是：

```text
append  -> 追加一个新的 itemId
remove  -> 删除对应位置的 itemId
render  -> getItemKey(arrayPath, index)
```

它不向 model 写入 `_id`，因此提交数据仍然只包含业务字段。当前 v1 只支持 append/remove，不支持任意 reorder；如果以后要支持拖拽，需要同时定义 itemId 的移动规则。

### 8.3 调度不变量

每次 flush 遵守这些规则：

1. model 写入是唯一会进入队列的变化。
2. runtimeState 变化不会反向触发表达式，因为 v1 表达式不读取 runtimeState。
3. 副作用只执行一次；同一轮 flush 中重复命中同一个 effect 会被跳过。
4. 所有新产生的 model 路径重新入队，处理级联 clear。
5. 超过 `maxSteps` 时记录 `STEP_LIMIT` 并抛出错误，避免无限循环。

### 8.4 `src/form-engine/useFormEngine.ts`

```ts
import { reactive, shallowReactive } from "vue";

import { FormEngineError } from "./errors";
import { collectDependencies, createFunctionExpressionEvaluator } from "./expression";
import {
  getByPath,
  isPlainEmptyValue,
  isRecord,
  joinPath,
  normalizePath,
  pathsIntersect,
  setByPath,
} from "./path";
import { compileSchema } from "./schema";
import type {
  CompiledExpression,
  CompiledField,
  EngineIssue,
  ExpressionContext,
  ExpressionEvaluator,
  ExpressionRule,
  FormEngine,
  FormEngineDebug,
  FormEngineOptions,
  FormModel,
  FunctionRegistry,
  Path,
  RuntimeFieldState,
  SideEffectRule,
} from "./types";

interface RepeatableRuntime {
  field: CompiledField;
  itemIds: string[];
  itemFields: Record<Path, CompiledField>;
  expressionRules: ExpressionRule[];
  sideEffectRules: SideEffectRule[];
}

function createRuntimeState(field: CompiledField): RuntimeFieldState {
  return {
    path: field.path,
    props: { ...field.props },
    custom: { ...field.custom },
    rules: field.rules.map((rule) => ({ ...rule })),
    visible: field.ui.visible ?? true,
  };
}

function isPromiseLike(value: unknown): value is Promise<unknown> {
  return (
    value !== null &&
    (typeof value === "object" || typeof value === "function") &&
    "then" in value &&
    typeof (value as { then?: unknown }).then === "function"
  );
}

function createDefaultItem(fields: readonly CompiledField[]): Record<string, unknown> {
  const item: Record<string, unknown> = {};

  for (const field of fields) {
    if (!field.field) continue;

    if (field.repeatable) {
      item[field.field] = [];
    } else if (field.children.length) {
      item[field.field] = createDefaultItem(field.children);
    } else {
      item[field.field] = undefined;
    }
  }

  return item;
}

export function useFormEngine(
  options: FormEngineOptions,
): FormEngine & { readonly debug: FormEngineDebug } {
  const compiled = compileSchema(options.schema);
  const model = reactive<FormModel>(structuredClone(options.initialModel ?? {})) as FormModel;
  const functions: FunctionRegistry = options.functions ?? {};
  const evaluator: ExpressionEvaluator = options.evaluator ?? createFunctionExpressionEvaluator();
  const maxSteps = options.maxSteps ?? 100;

  const runtimeFieldMap = shallowReactive<Record<Path, CompiledField>>({});
  const runtimeStates = reactive<Record<Path, RuntimeFieldState>>({});
  const identityMap = reactive<Record<Path, string[]>>({});
  const errors = reactive<EngineIssue[]>([]);
  const repeatableRuntimes = new Map<Path, RepeatableRuntime>();

  const staticExpressionRules: ExpressionRule[] = [];
  const staticSideEffectRules: SideEffectRule[] = [];

  let activeExpressionRules: ExpressionRule[] = [];
  let activeSideEffectRules: SideEffectRule[] = [];
  let expressionIndex: ReadonlyMap<Path, readonly ExpressionRule[]> = new Map();
  let sideEffectIndex: ReadonlyMap<Path, readonly SideEffectRule[]> = new Map();
  let ruleSequence = 0;
  let itemSequence = 0;
  let flushing = false;
  let queue: Path[] = [];
  const queuedPaths = new Set<Path>();

  function pushIssue(issue: EngineIssue): void {
    errors.push(issue);
  }

  function createContext(
    self: CompiledField,
    itemRoot: Path | null,
    itemIndex: number | null,
  ): ExpressionContext {
    const context: ExpressionContext = {
      $model: model,
      $self: self,
      $functions: functions,
    };

    if (itemRoot) {
      const item = getByPath(model, itemRoot);

      if (isRecord(item)) {
        context.$item = item;
      }
    }

    if (itemIndex !== null) {
      context.$index = itemIndex;
    }

    return context;
  }

  function resolveExpressionDependency(
    dependency: { type: "model" | "item"; path: string },
    itemRoot: Path | null,
  ): Path | null {
    if (dependency.type === "model") {
      return normalizePath(dependency.path);
    }

    if (!itemRoot) {
      return null;
    }

    return joinPath(itemRoot, dependency.path);
  }

  function resolveEffectTarget(target: string, itemRoot: Path | null): Path {
    const withoutRootPrefix = target.startsWith("$root.") ? target.slice("$root.".length) : target;

    if (itemRoot && !target.startsWith("$root.")) {
      return joinPath(itemRoot, withoutRootPrefix);
    }

    return normalizePath(withoutRootPrefix);
  }

  function compileRulesForField(
    field: CompiledField,
    itemRoot: Path | null,
    itemIndex: number | null,
    expressionRules: ExpressionRule[],
    sideEffectRules: SideEffectRule[],
  ): void {
    for (const [targetPath, expression] of Object.entries(field.expressions)) {
      try {
        const compiledExpression = evaluator.compile(expression);
        const deps = collectDependencies(expression)
          .map((dependency) => resolveExpressionDependency(dependency, itemRoot))
          .filter((path): path is Path => Boolean(path));

        expressionRules.push({
          id: `expr-${ruleSequence++}`,
          ownerPath: field.path,
          targetPath,
          expression,
          compiled: compiledExpression,
          deps,
          itemRoot,
          itemIndex,
        });
      } catch (cause) {
        pushIssue({
          code: "EXPRESSION_COMPILE",
          message: `Cannot compile expression for "${field.path}".`,
          path: field.path,
          expression,
          cause,
        });
      }
    }

    for (const effect of field.effects) {
      let compiledWhen: CompiledExpression | null = null;

      if (effect.when) {
        try {
          compiledWhen = evaluator.compile(effect.when);
        } catch (cause) {
          pushIssue({
            code: "EXPRESSION_COMPILE",
            message: `Cannot compile effect condition for "${field.path}".`,
            path: field.path,
            expression: effect.when,
            cause,
          });
          continue;
        }
      }

      sideEffectRules.push({
        id: `effect-${ruleSequence++}`,
        sourcePath: field.path,
        type: effect.type,
        when: effect.when ?? null,
        compiledWhen,
        targetPaths: effect.targets.map((target) => resolveEffectTarget(target, itemRoot)),
        itemRoot,
        itemIndex,
      });
    }

    for (const child of field.children) {
      compileRulesForField(child, itemRoot, itemIndex, expressionRules, sideEffectRules);
    }
  }

  function materializeField(
    field: CompiledField,
    rootPath: Path,
    itemIndex: number,
  ): CompiledField {
    const path = joinPath(rootPath, field.path);
    const parentPath = field.parentPath ? joinPath(rootPath, field.parentPath) : rootPath;

    return {
      ...field,
      key: path,
      path,
      parentPath,
      children: field.children.map((child) => materializeField(child, rootPath, itemIndex)),
      itemRoot: rootPath,
      itemIndex,
    };
  }

  function registerRuntimeTree(
    field: CompiledField,
    itemFields: Record<Path, CompiledField>,
  ): void {
    itemFields[field.path] = field;
    runtimeFieldMap[field.path] = field;
    runtimeStates[field.path] = createRuntimeState(field);

    for (const child of field.children) {
      registerRuntimeTree(child, itemFields);
    }
  }

  function registerStaticTree(field: CompiledField): void {
    runtimeFieldMap[field.path] = field;
    runtimeStates[field.path] = createRuntimeState(field);

    for (const child of field.children) {
      registerStaticTree(child);
    }
  }

  function syncRepeatable(field: CompiledField): void {
    const arrayPath = field.path;
    let list = getByPath(model, arrayPath);

    if (list === undefined) {
      list = [];
      setByPath(model, arrayPath, list);
    }

    if (!Array.isArray(list)) {
      pushIssue({
        code: "REPEATABLE_INVALID",
        message: `Repeatable model value must be an array: "${arrayPath}".`,
        path: arrayPath,
      });
      return;
    }

    const previous = repeatableRuntimes.get(arrayPath);

    if (previous) {
      for (const fieldPath of Object.keys(previous.itemFields)) {
        delete runtimeFieldMap[fieldPath];
        delete runtimeStates[fieldPath];
      }
    }

    const itemIds = [...(identityMap[arrayPath] ?? [])];

    while (itemIds.length < list.length) {
      itemIds.push(`item-${++itemSequence}`);
    }

    if (itemIds.length > list.length) {
      itemIds.length = list.length;
    }

    identityMap[arrayPath] = itemIds;

    const itemFields: Record<Path, CompiledField> = {};
    const expressionRules: ExpressionRule[] = [];
    const sideEffectRules: SideEffectRule[] = [];

    list.forEach((_, index) => {
      const rootPath = `${arrayPath}[${index}]`;

      for (const rawItemField of field.itemSchema) {
        const itemField = materializeField(rawItemField, rootPath, index);

        registerRuntimeTree(itemField, itemFields);
        compileRulesForField(itemField, rootPath, index, expressionRules, sideEffectRules);
      }
    });

    repeatableRuntimes.set(arrayPath, {
      field,
      itemIds,
      itemFields,
      expressionRules,
      sideEffectRules,
    });
  }

  function refreshRuleIndexes(): void {
    activeExpressionRules = [
      ...staticExpressionRules,
      ...[...repeatableRuntimes.values()].flatMap((runtime) => runtime.expressionRules),
    ];

    activeSideEffectRules = [
      ...staticSideEffectRules,
      ...[...repeatableRuntimes.values()].flatMap((runtime) => runtime.sideEffectRules),
    ];

    const expressionMap = new Map<Path, ExpressionRule[]>();
    const effectMap = new Map<Path, SideEffectRule[]>();

    for (const rule of activeExpressionRules) {
      for (const dependency of rule.deps) {
        const bucket = expressionMap.get(dependency) ?? [];
        bucket.push(rule);
        expressionMap.set(dependency, bucket);
      }
    }

    for (const rule of activeSideEffectRules) {
      const bucket = effectMap.get(rule.sourcePath) ?? [];
      bucket.push(rule);
      effectMap.set(rule.sourcePath, bucket);
    }

    expressionIndex = expressionMap;
    sideEffectIndex = effectMap;
  }

  function getClearValue(path: Path): unknown {
    const field = runtimeFieldMap[path];

    if (!field) return undefined;
    if (field.repeatable) return [];
    if (field.children.length) return {};
    return undefined;
  }

  function applyExpression(rule: ExpressionRule): void {
    const state = runtimeStates[rule.ownerPath];
    const self = runtimeFieldMap[rule.ownerPath];

    if (!state || !self) {
      pushIssue({
        code: "EXPRESSION_RUNTIME",
        message: `Missing runtime state for "${rule.ownerPath}".`,
        path: rule.ownerPath,
        expression: rule.expression,
      });
      return;
    }

    try {
      const value = rule.compiled(createContext(self, rule.itemRoot, rule.itemIndex));

      if (isPromiseLike(value)) {
        throw new FormEngineError(
          "EXPRESSION_RUNTIME",
          `Async expression is not supported: ${rule.expression}`,
          {
            path: rule.ownerPath,
            expression: rule.expression,
          },
        );
      }

      setByPath(state as unknown as Record<string, unknown>, rule.targetPath, value);
    } catch (cause) {
      pushIssue({
        code: "EXPRESSION_RUNTIME",
        message: `Expression failed for "${rule.ownerPath}".`,
        path: rule.ownerPath,
        expression: rule.expression,
        cause,
      });
    }
  }

  function executeEffect(rule: SideEffectRule): void {
    const self = runtimeFieldMap[rule.sourcePath];

    if (!self) return;

    if (rule.compiledWhen) {
      try {
        const passed = rule.compiledWhen(createContext(self, rule.itemRoot, rule.itemIndex));

        if (isPromiseLike(passed)) {
          throw new FormEngineError(
            "EXPRESSION_RUNTIME",
            `Async effect condition is not supported: ${rule.when ?? ""}`,
            {
              path: rule.sourcePath,
              ...(rule.when ? { expression: rule.when } : {}),
            },
          );
        }

        if (!passed) return;
      } catch (cause) {
        pushIssue({
          code: "EXPRESSION_RUNTIME",
          message: `Effect condition failed for "${rule.sourcePath}".`,
          path: rule.sourcePath,
          ...(rule.when ? { expression: rule.when } : {}),
          cause,
        });
        return;
      }
    }

    if (rule.type !== "clear") return;

    for (const targetPath of rule.targetPaths) {
      const currentValue = getByPath(model, targetPath);
      const nextValue = getClearValue(targetPath);

      if (isPlainEmptyValue(currentValue) && isPlainEmptyValue(nextValue)) {
        continue;
      }

      setByPath(model, targetPath, nextValue);
      enqueue(targetPath);
    }
  }

  function findAffectedExpressions(changedPath: Path): readonly ExpressionRule[] {
    const matched = new Set<ExpressionRule>();

    for (const [dependency, rules] of expressionIndex) {
      if (pathsIntersect(changedPath, dependency)) {
        for (const rule of rules) matched.add(rule);
      }
    }

    return [...matched];
  }

  function findAffectedEffects(changedPath: Path): readonly SideEffectRule[] {
    const matched = new Set<SideEffectRule>();

    for (const [sourcePath, rules] of sideEffectIndex) {
      if (pathsIntersect(changedPath, sourcePath)) {
        for (const rule of rules) matched.add(rule);
      }
    }

    return [...matched];
  }

  function enqueue(path: Path): void {
    const normalized = normalizePath(path);

    if (queuedPaths.has(normalized)) return;

    queuedPaths.add(normalized);
    queue.push(normalized);
  }

  function flush(): void {
    if (flushing) return;

    flushing = true;
    const executedEffects = new Set<string>();
    let steps = 0;

    try {
      while (queue.length) {
        steps += 1;

        if (steps > maxSteps) {
          const error = new FormEngineError(
            "STEP_LIMIT",
            `Expression scheduler exceeded ${maxSteps} steps.`,
          );

          pushIssue({
            code: "STEP_LIMIT",
            message: error.message,
          });

          throw error;
        }

        const changedPath = queue.shift();

        if (!changedPath) continue;

        queuedPaths.delete(changedPath);

        for (const rule of findAffectedExpressions(changedPath)) {
          applyExpression(rule);
        }

        for (const rule of findAffectedEffects(changedPath)) {
          if (executedEffects.has(rule.id)) continue;
          executedEffects.add(rule.id);
          executeEffect(rule);
        }
      }
    } finally {
      flushing = false;
      queue = [];
      queuedPaths.clear();
    }
  }

  function schedule(path: Path): void {
    enqueue(path);
    flush();
  }

  function setInitialRuntime(): void {
    for (const field of compiled.fields) {
      registerStaticTree(field);
      compileRulesForField(field, null, null, staticExpressionRules, staticSideEffectRules);
    }

    for (const repeatable of compiled.repeatables) {
      syncRepeatable(repeatable);
    }

    refreshRuleIndexes();

    for (const rule of activeExpressionRules) {
      applyExpression(rule);
    }
  }

  function getValue(path: Path): unknown {
    return getByPath(model, normalizePath(path));
  }

  function setValue(path: Path, value: unknown): void {
    const normalized = normalizePath(path);
    setByPath(model, normalized, value);
    schedule(normalized);
  }

  function append(arrayPath: Path): void {
    const normalized = normalizePath(arrayPath);
    const field = runtimeFieldMap[normalized];

    if (!field?.repeatable) {
      pushIssue({
        code: "REPEATABLE_INVALID",
        message: `Cannot append to non-repeatable path "${normalized}".`,
        path: normalized,
      });
      return;
    }

    const current = getByPath(model, normalized);
    const list = Array.isArray(current) ? [...current] : [];
    const nextItem = createDefaultItem(field.itemSchema);

    list.push(nextItem);
    setByPath(model, normalized, list);

    syncRepeatable(field);
    refreshRuleIndexes();
    schedule(`${normalized}[${list.length - 1}]`);
  }

  function remove(arrayPath: Path, index: number): void {
    const normalized = normalizePath(arrayPath);
    const field = runtimeFieldMap[normalized];

    if (!field?.repeatable) {
      pushIssue({
        code: "REPEATABLE_INVALID",
        message: `Cannot remove from non-repeatable path "${normalized}".`,
        path: normalized,
      });
      return;
    }

    const current = getByPath(model, normalized);

    if (!Array.isArray(current) || index < 0 || index >= current.length) {
      pushIssue({
        code: "REPEATABLE_INVALID",
        message: `Invalid item index ${index} for "${normalized}".`,
        path: normalized,
      });
      return;
    }

    const identity = [...(identityMap[normalized] ?? [])];
    identity.splice(index, 1);
    identityMap[normalized] = identity;

    const list = [...current];
    list.splice(index, 1);
    setByPath(model, normalized, list);

    syncRepeatable(field);
    refreshRuleIndexes();
    schedule(normalized);
  }

  function getFieldState(path: Path): RuntimeFieldState | undefined {
    return runtimeStates[normalizePath(path)];
  }

  function getItemKey(arrayPath: Path, index: number): string {
    const normalized = normalizePath(arrayPath);
    return identityMap[normalized]?.[index] ?? `${normalized}[${index}]`;
  }

  const debug: FormEngineDebug = {
    get expressionRules() {
      return activeExpressionRules;
    },
    get sideEffectRules() {
      return activeSideEffectRules;
    },
    get identityMap() {
      return identityMap;
    },
  };

  setInitialRuntime();

  return {
    model,
    schema: compiled.fields,
    runtimeFieldMap,
    errors,
    getValue,
    setValue,
    append,
    remove,
    getFieldState,
    getItemKey,
    debug,
  };
}
```

### 8.5 这段代码里最容易出错的地方

#### 表达式目标为什么是字段相对路径

`dept` 的表达式目标是 `props.disabled`，不是 `dept.props.disabled`。如果目标允许同时使用两种写法，后续 repeatable 的相对路径判断会变得非常混乱。统一规则之后：

```text
字段自己的表达式 target -> state[ownerPath] 内部路径
副作用 targets          -> model 路径
数组项副作用            -> 默认相对当前 item，$root. 表示根 model
```

#### 为什么初始化不跑副作用

如果初始化执行 `clear`，用户传入的 `initialModel` 会在第一次渲染前被清空。副作用只应该响应用户或业务代码造成的值变化。

#### 为什么 `runAllExpressions` 不排序

v1 的表达式依赖只来自 model，表达式结果写入 runtimeState，后一个表达式不会读取前一个表达式的 runtimeState。因此没有需要排序的表达式链路。若以后加入表达式间依赖，必须先引入拓扑排序，不能只靠数组顺序。

## 九、渲染层

### 9.1 渲染层只做三件事

渲染层不应重新实现联动逻辑，它只负责：

1. 根据 `CompiledField` 决定渲染普通字段、对象组还是 repeatable。
2. 从 `getFieldState(path)` 读取表达式结果。
3. 通过组件注册表找到控件，并调用 `engine.setValue`。

### 9.2 `src/form-engine/renderer/context.ts`

### 9.12 渲染层的边界

- `RenderField` 不计算表达式，只读取已经计算好的 state。
- `RenderArrayItem` 只取当前 item 根路径下的直接字段；普通 children 由 `RenderField` 自己递归。
- `registry.ts` 允许业务项目覆盖 `input`、`select` 等名称，不需要修改引擎。
- `createComponentRegistry` 使用 `Object.freeze` 防止运行期动态注册造成不可预测的重渲染。

        "custom.options": "$functions.getDeptOptions($model.userType)",
      },
    },
  ];
}

describe("useFormEngine", () => {
  it("evaluates expressions without mutating schema", () => {
    const schema = createLinkageSchema();
    const engine = useFormEngine({
      schema,
      initialModel: { name: "", userType: "", dept: "default" },
      functions: {
        getDeptOptions: (...args) =>
          args[0] === "admin"
            ? [{ label: "技术部", value: "tech" }]
            : [{ label: "访客组", value: "guest" }],
      },
    });

    expect(schema[2]?.props?.disabled).toBe(false);
    expect(engine.getFieldState("dept")?.visible).toBe(false);

    engine.setValue("userType", "admin");

    expect(engine.getFieldState("dept")?.visible).toBe(true);
    expect(engine.getFieldState("dept")?.rules[0]?.required).toBe(true);
    expect(engine.getValue("dept")).toBeUndefined();

    engine.setValue("name", "Ada");

    expect(engine.getFieldState("dept")?.props.disabled).toBe(false);
  });

  it("cascades clear effects and stops at a fixed point", () => {
    const engine = useFormEngine({
      schema: [
        {
          field: "a",
          component: "input",
          effects: [{ type: "clear", targets: ["b"] }],
        },
        {
          field: "b",
          component: "input",
          effects: [{ type: "clear", targets: ["c"] }],
        },
        { field: "c", component: "input" },

      initialModel: { a: "", b: "B", c: "C" },

    engine.setValue("a", "A");

  it("rebuilds repeatable fields and keeps identities outside model", () => {
    const engine = useFormEngine({
      schema: [

          field: "contacts",

          itemSchema: [
            { field: "name", component: "input" },

              field: "phone",
              component: "input",

              expressions: { "props.disabled": "!$item.name" },
            },
          ],
        },
      ],
      initialModel: { contacts: [] },
    });

    engine.append("contacts");
    engine.append("contacts");

    const secondKey = engine.getItemKey("contacts", 1);

    engine.setValue("contacts[0].name", "Tom");

    expect(engine.getFieldState("contacts[0].phone")?.props.disabled).toBe(false);

    engine.remove("contacts", 0);

    expect(engine.getItemKey("contacts", 0)).toBe(secondKey);
    expect(engine.model.contacts).toEqual([{ name: undefined, phone: undefined }]);
    expect(JSON.stringify(engine.model)).not.toContain("_id");
  });

  it("records expression errors instead of breaking other fields", () => {
    const engine = useFormEngine({
      schema: [
        {
          field: "broken",

        { field: "stable", component: "input" },

    });

          field: "flag",

        },

        compile: () => () => false,
      },
    });

  });

## 十二、边界、失败模式与演进方向

### 12.1 当前明确不支持的场景

```text
嵌套 repeatable
async expression / async effect
表达式依赖另一个表达式的结果
$model[key] 动态路径
任意拖拽排序 repeatable
跨表单实例共享运行时状态
不可信 schema
```

这些能力不是简单加一个分支就能安全实现。例如表达式依赖表达式，需要先建立拓扑图和环检测；动态路径需要改变依赖收集模型；异步表达式需要定义取消、竞态和 loading 状态。

### 12.2 性能边界

当前 `pathsIntersect` 会遍历依赖索引。对于几十到几百个字段的个人表单足够；如果字段数达到数千，应把依赖索引改为前缀树或按数组根路径分桶。

repeatable 增删会重建整个数组的运行时字段。复杂度是 `O(array length)`，换取的是索引变化后规则绝对不会残留。只有当实际测量证明它成为瓶颈时，再实现局部重建。

### 12.3 安全边界

默认求值器使用 `Function`。它适合本地提交的 schema，不适合：

- 用户在浏览器中自由编辑 schema。
- 从服务端接收未经审核的表达式。
- 运行在禁止 `unsafe-eval` 的 CSP 环境。

替换方式是实现同样的 `ExpressionEvaluator`：

```ts
import type { ExpressionEvaluator } from "./types";

export function createSafeEvaluator(): ExpressionEvaluator {
  return {
    compile(expression) {
      // 解析成 AST，只允许比较、逻辑、算术和白名单函数。
      return (context) => {
        void expression;
        void context;
        return undefined;
      };
    },
  };
}
```

### 12.4 推荐演进顺序

1. 先把默认 evaluator 替换成 AST 白名单实现，并保留同一套 ExpressionRule。
2. 为 `ExpressionContext` 增加只读的 `$state`，然后支持依赖 runtimeState 的表达式；此时必须加入拓扑排序。
3. 为 repeatable 增加 move 操作，identity map 从列表改为 `{ id, value }` 或独立 index 映射。
4. 加入异步 options/effect 时，先定义 loading、取消和错误状态，不要直接让表达式返回 Promise。
5. 最后再把引擎抽成 package，并补充 API 文档、Changesets 与发布流程。

### 12.5 最终结论

动态表单引擎的可维护性来自三个不变量：

1. schema 只描述结构，运行时不改 schema。
2. model 只保存业务值，所有修改必须经过统一写入口。
3. runtimeState 承载派生结果，表达式不产生隐式副作用。

当这三条边界稳定后，组件注册表、repeatable、调度器和 UI 库适配都只是可替换的实现细节。
